# LegalEase

## AI-Powered Legal Document Generator

LegalEase is a Generative AI-powered application that helps users generate structured legal documents such as contracts, Non-Disclosure Agreements (NDAs), and other agreements based on user-provided details.

## Features

- Generate legal documents using Generative AI
- Support for contracts, NDAs, and agreements
- Accept user details such as:
  - Document type
  - Parties involved
  - Terms and conditions
  - Effective date
- Generate structured and readable legal documents
- Simple and user-friendly interface

## Technology Stack

- Python
- Generative AI
- Google Gemini API
- Flask
- HTML, CSS, JavaScript
